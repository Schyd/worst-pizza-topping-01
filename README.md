One funny line pitching the worst pizza topping we could invent: a sardine
pizza so fishy the cat moves out. `main.py` copies `entry.txt` verbatim to
the output directory (`MAKEFUN_OUTPUT_DIR`, default `./output`), exiting 0.
Run it twice and the two outputs are byte-identical.
